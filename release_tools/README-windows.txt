超压预测软件 0.14.1 · Windows x64 CPU 版

1. 完整解压 ZIP 到本地文件夹。不要直接在压缩包内运行。
2. 双击 PressurePrediction.exe。保留 PressureWorker.exe 与 _internal 文件夹。
3. 不需要安装 Python、Conda 或 CUDA。CPU 版训练速度取决于电脑性能。
4. 首次运行创建空白项目；从左侧项目对象右键导入井、地震、层位和时深关系。
5. 项目与默认成果保存在 %LOCALAPPDATA%\PressurePrediction，也可另存项目。
6. 时深系数和物理参数仅为格式示例，必须按项目实际情况设置后再用于预测。
7. 本包不含实际井数据、SEG-Y、预训练模型和历史成果。MLP 预测需先训练或加载兼容模型；传统 Eaton 预测无需训练模型。
8. 现阶段训练算法为逐点 MLP；RF 与 XGBoost 尚未实现。

本版本未经数字签名。遇到启动失败时保留错误信息，并向维护者报告。
常用操作
· 传统压力预测：导入深度与 AC，点击“传统压力预测”，生成趋势图、取两点并明确采用，再执行 Eaton 井压力预测。
· 混合分道：同井多选曲线，右键绘制，打开“分道与曲线样式…”。相同道号叠加，不同道号独立显示。
· 曲线样式：每条曲线可设线、点或线＋点，并修改线型、颜色、点形状、大小。
· 图例遮挡：打开“图例设置…”，选择“图框外上方”，或勾选“允许拖动”后直接拖动图例。
· 窗口关闭后：从左侧对象或顶部任务入口重新打开；图件可通过绘图工具栏导出。

传统 Eaton 上覆压力采用平均岩石密度近似，压力系数为预测压力 / 静水压力。示例参数不是任何工区的标定结果。
本包附带空白项目，开发者的测试资料未包含在内。
