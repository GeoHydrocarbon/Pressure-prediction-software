# 超压预测软件 0.15.0

- 模型训练增加 RF 与 XGBoost，各自独立参数设置；模型可重命名并联动后续预测。
- 井坐标支持 TXT；轨迹支持深度、方位角、井斜角，提供行号与表头预览。
- 逐井应用已导入的时深关系，Map 与剖面显示井轨迹及可配置叠加曲线。
- 岩石物理工作台：基础输入自动正演，矿物曲线/常数和常见矿物预设，单/双孔隙 DEM、临界孔隙度、油水流体及 Gassmann 基线。
- 实时预览最多 240 个深度样点，连续修改只采用最新输入；完整井段计算、标定和成果曲线保存由用户主动执行。
- 保留 SEG-Y 道头设置预检、传统 Eaton 预测、混合测井道、逐曲线线点样式和图例设置。

下载 Windows x64 CPU ZIP 后完整解压，运行 PressurePrediction.exe；保留 PressureWorker.exe 和 _internal。无需安装 Python、Conda 或 CUDA。

运行包附空白项目，不含开发者井资料、地震体、模型或历史成果。参数初值需结合项目实际资料核对。

本次本地运行包基于已校验的 CPU 运行库重建，补齐 scikit-learn 1.9.0、XGBoost 3.3.0、Narwhals 2.23.0 及 RockPhyPy 资源；通过移除开发环境路径后的训练、SEG-Y、Eaton、GUI 和岩石物理验证。源码仍支持标准 PyInstaller 构建。
