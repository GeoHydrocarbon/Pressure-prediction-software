# 测井岩石物理基线建模

从顶部“岩石物理建模”进入，首个页面为测井工作流；原有独立算法位于“模型工具箱”。计算使用独立后台进程，可在窗口底部取消任务。

## 交互式工作台与实时预览

宽窗口左侧为设置，右侧为曲线对比和交会图；窄窗口自动上下排列，可拖动分隔条调整空间。默认只展开“基础输入”，基质、骨架流体、质控和标定按需展开；“方案管理”集中提供保存、复制、导入、导出等操作，绘图样式和图例集中在“绘图设置”菜单。

选择井后自动带入井段并匹配常见曲线。基础正演只需要井的深度采样和孔隙度来源（曲线或明确填写的常数）。实测 Vp、Vs、密度可稍后加入，用于对比和误差统计。缺少矿物或流体资料时采用界面明确列出的当前常数；它们是可修改的建模初值，不代表井的实测性质。

默认启用“自动更新”：输入稳定约半秒后后台计算，连续修改会取消或丢弃过期任务，只显示最新输入的结果。也可暂停自动更新，手动点击“刷新预览”。输入不完整时不会弹出反复报错的窗口，状态栏会提示需要完善的内容；上一次图件会明确标记为旧结果。

自动预览最多均匀选择 240 个原始深度样点，显示实际预览数、全井段样点数以及预览样点的误差统计；不会跨越抽样隐藏的无效数据和深度间断连线。它仅执行当前模型正演，不自动运行扫描或优化，不创建成果文件，也不写入井曲线。曲线样式、分道和已移除曲线在更新时保留；“恢复默认图”重新显示全部对比曲线。

需要正式成果时点击“计算并保存成果”；若选择了标定，按钮显示“运行标定并保存成果”。这会按完整井段计算并打开中央成果窗口，随后可选择成果曲线保存到井。关闭工作台会停止自动计算，重新打开后按当前设置刷新。

## 1. 选择井和输入

先通过项目对象中的井导入曲线，再选择建模井、方案名称和深度范围。支持一口井保存多个方案，或复制方案后更换井及曲线映射。

在“基础输入”中匹配孔隙度和实测参考，勾选补充输入后可设置 Sw、温度、压力以及可选 TOC。每项可以选择井曲线，也可以明确输入常数。默认常数和物性只是示例，需要根据实际资料修改。

Vp/纵波时差、Vs/横波时差、密度作为实测参考。没有横波曲线也可以正演 Vs；该情况下不计算 Vs 验证误差。参考曲线用于对比或标定，不作为模型速度、密度的直接输入。

核对输入单位，特别是百分数与小数、us/ft 与 us/m、质量分数与体积分数。地层压力使用 MPa/kPa/psi；温度为摄氏度；实测声波时差自动转换为 m/s。

点击“预览输入与质控”可检查有效样本数、无效原因和前 100 行。井内各曲线默认按相同深度匹配，不自动插值。启用插值后，仅在相邻有效采样点间、指定最大间隔内插值；不外推，不跨越显式缺失点。结果保留无效行的原深度，模型值留空。

## 2. 基质与骨架

在“基质组成”先选择常见矿物，再点击“添加矿物”。预设包含石英、方解石、白云石、长石、伊利石、黏土、黄铁矿、白云母，带入可修改的密度、体积模量 K、剪切模量 G 初值。黏土为混合组分示例；长石、黏土和白云母初值参考 [JGE 文献表 3](https://academic.oup.com/view-large/325015832)，其余沿用参考工程配置。预设初值应结合实际资料核对。

选择“自定义矿物”添加其它组分，填写名称、密度、K、G。矿物比例来源框点击文字区或右侧箭头均可展开当前井曲线列表，选择空白项时使用比例常数。矿物名称与物性参数均可自行修改，所选曲线随方案保存。

矿物比例解释为无机固体中的组成。若为质量分数，软件依据各矿物密度转换成体积分数。是否归一化、是否将负矿物比例置零由用户选择，处理记录随成果保存。未启用处理时，不符合要求的样本会标记无效。

启用干酪根时，TOC 解释为干固体总质量中的碳质量分数，干酪根质量分数为 TOC / 干酪根碳比例；无机矿物占据剩余固体质量。不会将 TOC 直接当作干酪根体积分数，也不会静默截断异常 TOC。

基质混合可选 Hill、Voigt、Reuss。骨架可选临界孔隙度、单孔隙 DEM、双孔隙 DEM；双孔隙可设置软孔占比、硬软孔纵横比和加孔顺序。分层表支持对不同井段覆盖参数，同一井段可填写多个不同参数；重叠的不同井段会被拒绝。分层区间左闭右开，包含建模终点。

流体为油水体系，使用 BW 内核计算温压条件下的性质，按 Sw 混合。气油比为 0 时使用死油，非零时使用活油。随后通过 Gassmann 计算饱和模量及速度、密度。

Gassmann 是低频各向同性基线近似。声波测井的频率差异、页岩各向异性等，需要结合资料解释。裂缝和各向异性反演不属于本阶段工作流。

## 3. 正演、敏感性与标定

首次建议选择“仅正演”，检查实测与模型曲线差异。需要标定时，在“敏感性与标定”选择：

- 参数扫描：选择 1～2 个参数、上下限和扫描点数，最多 400 组。
- 自动标定：选择 1～3 个参数、上下限和最大迭代数。

标定参数必须适用于当前骨架模型。分层已覆盖的参数不能同时做全井标定。各参考曲线采用相对误差，按有效样本数归一化并乘以用户权重；未提供的曲线不参与。模型密度对部分骨架参数不敏感，不能单独用密度来标定这些参数。

设置标定井段和单独的验证井段，两者不能重叠。验证起终点相等时不启用独立验证。标定最多采用指定数量的沿深度均匀抽样点，抽样深度会被记录；最终使用选定参数计算整个建模区间。误差统计分别列出初始模型、最终全区间、实际标定样本和独立验证结果。

## 4. 查看和保存

结果在中央绘图窗口打开，包含综合对比图、可按曲线着色的交会图、敏感性/优化过程、数据表和误差记录。

综合图复用原有“分道与曲线样式”和“图例设置”：相同道号叠加，不同道号独立；每条曲线可选择线、点、线加点及其颜色、粗细、形状、大小。点击“保存当前图件设置”保存分道、样式、图例和交会图选择，下次打开此成果恢复。图件支持 PNG、PDF、SVG；数据支持 CSV、JSON。

“保存成果曲线到井”允许选择 VP_RP、VS_RP、DEN_RP、AC_RP、IP_RP、VPVS_RP、K_RP、G_RP 并命名。仅增加派生曲线引用，不覆盖原始曲线；重名会被拒绝，可修改名称后保存。派生曲线可以在项目井对象中绘图，也可用于后续分析。

“重新编辑 / 使用标定参数”恢复本次实际采用的方案，修改后可以再次计算。每次运行生成独立成果目录，记录输入文件 SHA256、曲线映射、单位、原始和采用的参数、内核版本及源码哈希。

方案可在项目中保存、复制、载入、删除，也可以导出或导入 JSON。结果数据及方案文件应随项目一起保留；移动原始输入文件后，需更新曲线引用。
